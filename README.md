# Telegram-бот для оздоровительного центра

Готовый бот для записи на услуги (ЛФК, массаж), сбора анкет питания и оформления подарочных сертификатов.

## Что умеет бот
- 📋 Показывает услуги и цены (ЛФК, массаж, пакеты).
- 📝 Принимает заявки на запись: имя, телефон, адрес, удобное время.
- 🥗 Собирает анкеты питания для составления индивидуального плана.
- 🎁 Оформляет подарочные сертификаты (с данными получателя).
- 📩 Отправляет все заявки администратору в Telegram.

## Стек технологий
- Python 3
- python-telegram-bot (v20+)
- Flask (для health-check на Render)
- Render (хостинг)
